RIFTBOUND TRACKER v4

INSTALL / UPDATE
1. Upload every file in this folder to the same web folder as the existing app.
2. Keep the filenames index.html, manifest.json, sw.js, RiftboundS.png and RiftboundL.jpg unchanged.
3. Open the app once while online so the new offline cache installs.
4. Fully close and reopen the installed app. If the old layout remains, clear the site's cache and reopen it.

DATA MIGRATION
- Existing v2/v3 profiles, current match, stats and history remain available when installed at the same site address in the same browser/device.
- Export Backup / Import Backup can move a profile between browsers or devices.

NEW IN v4
- Tabletop mode with the opponent panel optionally rotated 180 degrees.
- First-player randomizer, current-player glow and turn counter.
- Match timer with 45/50/55-minute presets, custom time, pause, warnings and optional automatic overtime.
- Optional screen wake lock while the timer or tabletop mode is active.
- Expanded Riftbound XP controls: -1, +1, +2, +3, exact value, larger adjustments and long-press reset.
- Your leader, opponent leader, opponent deck/colors, match type and match notes.
- Editable and individually deletable match-history entries.
- Leader, opposing-leader, first-player and match-type statistics.
- Quick match keeps your deck, leader, event and format while clearing the previous opponent and scores.
- Optional haptic and sound feedback.
- Swipe left on the tracker background to undo.
- Hold the Reset Match button for one second to prevent accidental resets.
- Current match, timer, XP and turns survive refreshes.

BROWSER NOTES
- Fullscreen, vibration and screen wake lock depend on browser/device support.
- iPhone/iPad browsers may limit fullscreen and vibration features, but all scoring and tracking functions still work.
