Riftbound Tracker · Ahri Edition v4.8

READY-TO-UPLOAD PACKAGE

Upload these files to the root of your GitHub repository:
- index.html
- manifest.json
- sw.js
- AhriIcon180.png
- AhriIcon192.png
- AhriIcon512.png

AhriIconOriginal.png is included as a high-resolution source image but is not required for the app to work.

After GitHub Pages deploys:
1. Remove the currently installed app from your phone.
2. Clear site data for your GitHub Pages address.
3. Open the website again.
4. Install/Add to Home Screen again.

The new installed icon is the Ahri fox-spirit emblem.
